# SVS 钢琴窗：优化版 TuneLab 操作对齐

2026-10-06。依据 [优化版实测记录](TuneLab-optimized-editing-behavior.md) 和用户补充，限定于计划书内的独立 SVS 钢琴窗。普通 PianoRoll、音频框架及其他轨道未修改。

## 已实现行为

| 操作 | SVS 行为 |
| --- | --- |
| 铅笔工具空白按下、长按拖动 | 创建音符并拖动尾部；松开一次提交，切换工具或 Escape 取消预览 |
| 铅笔工具拖动既有音符主体 | 移动音符，保留时长 |
| 铅笔工具拖动首端/尾端 | 首端伸缩保持尾部，尾端伸缩保持起点；使用当前量化，支持撤销/重做 |
| 选择工具 | 空白选择/框选，双击空白创建；双击音符打开行内歌词输入 |
| 工具按钮、数字 1–5 | 同步选择、铅笔、音高画笔、锚点、平滑工具的状态；切换取消未完成手势，保留已提交曲线 |
| 参数区左键拖画 | 选择/铅笔模式也按自由笔绘制，仅覆盖经过的时间区间 |
| 参数区右键单击/长按拖动 | 局部/连续恢复曲线基线，保留区间外曲线；一次手势一次撤销，支持取消；只读结果拒绝编辑 |
| 参数曲线高级菜单 | Shift+右键或键盘菜单键保留锚点数值、连接/断开、曲线复制等计划内操作 |
| 音高画笔 | 连续自由绘制；音符淡化，切回音符工具后用户音高线淡化并保留，继续使用 LMMS 主题颜色 |
| 批量歌词 | 继续使用已有按音符时间排序的分词填充；两个音符输入两个汉字时各填一个字，行内输入仍把文本提交给单个音符 |
| 参数区显隐 | 工具栏 Parameters 开关控制区域显隐，状态进入已有编辑器持久化数据 |

参数右键重置写回插件声明的原始默认值。已有数值基础值偏移保持不变，显示和合成继续叠加该偏移；不会清空基础值、其他参数或音符。新生成曲线保留参数声明的 note/clip/track 作用域。Power、Soft、Mode 的类型、作用域和默认值纳入自动验证。

首端伸缩依据用户本轮实测补充，并验证向左延长、向右缩短及尾部不动。批量歌词和右键连续重置的参考证据按原记录区分用户确认与自动操作观察，不伪称重新进行 TuneLab 实机测试。

优化版波浪工具具体算法、简谱专用输入规则等没有充分确认且不在本轮既定范围，不增加相应功能。原有计划内直线/擦除工具继续保留。

## 验证与人工验收

Release 主程序、SVSExample 和 SVSIntegrationTest 前台编译；自动验证使用原生 Windows Qt 平台，子进程同样禁用 offscreen。新增测试覆盖创建/移动/首尾伸缩、事务撤销与取消、工具同步、输入数字不切换工具、时间顺序批量填词、参数自由笔与右键重置、区间外保留、只读门禁及离散参数作用域。

完整回归 **57 passed / 0 failed / 0 skipped**，结果和证据见计划书第 24 节及本机 `doc/svs/validation/SVS-TuneLab-alignment-*`。开发版原 lmms.exe 正在运行且工程未保存，初次替换因文件占用失败；保留该进程，最新主程序部署为 `build/svs-lmms-clean-install/lmms-svs-aligned.exe`。主程序、示例插件和测试程序均核对哈希，既有主题与独立配置保留。当前运行窗口仍是旧版本，人工体验应在结束该窗口后启动新文件。

用户指示本轮先修改、编译、提交推送，实机体验默认人工验收：布局、手感、系统 IME 和听感均标记 **MANUAL/PENDING**。本轮不启动 TuneLab、不使用 Computer Use、不打开原安装版 LMMS。

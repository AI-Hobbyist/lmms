# SVS pitch context actions

The piano-roll context menu adds **Clear hand-drawn pitch** and **Re-predict automatic pitch**. With no selection both apply to the whole current SVS clip; a note or anchor selection limits their scope. A single anchor resolves to its containing note, and an anchor outside notes never silently expands to the whole clip. Parameter lanes retain their existing operations. Freehand and parameter right-drag gestures remain unchanged; Shift+right click can open the pitch menu.

Clearing removes the hand-drawn override only in scope. Prediction restores automatic pitch in scope and creates per-note request tokens, saved in the existing clip editor state and included in undo checkpoints. Segment planning retains only tokens belonging to that segment, invalidating affected audio caches while retaining independent segment signatures. DiffSinger incorporates the token in pitch-stage tensor cache identity to actually rerun prediction; other stages continue using their valid SHA256 caches. Voices without a prediction module retain their existing note-pitch fallback.

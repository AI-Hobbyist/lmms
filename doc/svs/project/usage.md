# SVS 工程导入导出使用说明

从“文件”菜单进入“SVS 工程”，选择“导入SVS工程”或“导出SVS工程”。文件筛选按格式实际支持的方向显示；字幕、歌词、乐谱、图形及合成参数文件也在清单中，它们能表达的内容各不相同。

## 导入工程

1. 选择源文件和对应格式。
2. 检查该格式的导入选项，再确定。所有新建歌声轨直接以“未选定”导入，不需要选择或安装声库。
3. 阅读转换警告和逐项损失提示。可以取消；接受后，导入结果作为一个新的、尚未保存的 LMMS 工程打开。当前工程有未保存修改时，先按提示处理。
4. 在 SVS 钢琴窗检查歌词、读音和音高曲线，并选择所需歌手，完成编辑后保存为 LMMS 工程。

导入使用源工程解析出的编辑音高；选择声库不会重新生成曲线来替换它。源格式或解析器没有提供有效音高时，会提示音高损失。嵌入伴奏默认提取到本次导入资源中；若主动关闭提取，伴奏不会导入。外部伴奏文件缺失时，应补齐资源后重新导入。

未选定时根据音符生成正弦波试听，音素条显示歌词原文，侧栏提示“请选择一个歌手”。“未选定”仅是轨道绑定状态，不出现在引擎声库/插件列表。选定歌手后由引擎合成；可在编辑器中切回“未选定”。取消或导入失败会保留原工程。

## 导出工程

1. 在当前工程中准备 SVS 轨和音频轨，然后选择“导出SVS工程”。
2. 选择目标格式、文件名和转换选项。格式只能容纳一条歌声轨或伴奏轨时，明确选择要导出的轨道。
3. 检查轨道省略、格式限制、量化和其他转换损失；确认后才执行导出。
4. 目标文件已经存在时，检查整组文件的覆盖提示。完成后，按显示的路径找到结果。

导出取点击时的工程快照，仅包含 SVS 轨和音频轨。普通乐器轨、节拍轨及其他轨道不导出；歌声不会渲染成替代音频。没有安装声库也可以导出已有 SVS 音符和编辑数据。导出不改变当前工程文件名、修改状态或撤销记录。

伴奏裁剪、反向或增益需要物化时，会生成相应音频文件。保留工程文件及其全部伴随文件；VSQX 的相对伴奏放在同名 `.wavparts` 文件夹中。复制工程时应一起复制这些文件和文件夹。取消、转换失败或提交失败会保留原有完整输出。

## 格式选项

UST 的默认 Shift-JIS 编码无法表达所有中文和韩文。需要这些字符时，可选择格式已有的 UTF-8 编码，并确认接收软件支持 UTF-8。

单速度、单轨、无伴奏、无编辑音高或只输出歌词/图形的格式，不能保留完整歌声工程。转换结果应按相应格式的损失提示使用，不能将“文件可打开”视为完整往返保真。

损失提示也包含固定转换链的读回限制：独立读音可能被重算或写成歌词，轨道标题和混音状态可能回到默认值，音高可能经过帧采样和整数量化。它们不是完整音高保真结果。查看格式、受影响轨道和具体字段后，可取消或明确接受有损转换；未确认时不会写出文件。宿主无法表达的关键时间结构仍会拒绝导入。

MusicXML 的 `.musicxml`、`.xml` 与压缩 `.mxl` 后缀均可使用。UST 1.x 需要选择单轨；其已有的 2.x 选项可写出多轨，接收软件也须支持相应结构。

开发程序位于 `build/Release/lmms.exe`。转换使用随程序部署的独立运行时，使用者不需要安装系统 Python 或联网下载依赖。

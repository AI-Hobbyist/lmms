# Absolute curve reference defaults

Editable parameters declared with `mode:absolute` and a matching feedback parameter (same id, scope, type and unit) now display their read-only feedback values wherever no authored curve covers the timeline. There are no engine-id checks. Offset parameters and parameters without a matching feedback declaration retain their existing defaults.

Prediction is a display default, not copied into the editable curve. Drawing into a previously untouched absolute lane stores only the drawn interval; the remaining timeline continues to use automatic prediction. Right-drag reset removes that interval's override and restores the reference default. Existing authored curves are preserved. Before feedback exists, a reference-backed default has no predicted line to display.

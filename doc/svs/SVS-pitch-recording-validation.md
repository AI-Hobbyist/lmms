# Generic automatic pitch recordings

The former re-prediction action is now **音高重录**. This is a host capability available to any AI engine whose selected voice declares `pitch.prediction:true`. Returning pitch feedback without automatic prediction is insufficient. DiffSinger declares prediction only when its voicebank has a pitch module; SVS Example remains unavailable for this action. Read-only clips also reject recording and switching.

The sidebar stores a sequence of recording snapshots, current recording number and exact uint32 seed. Recording 0 retains the initial prediction state. New recordings append rather than overwrite earlier entries. The **固定当前种子** checkbox keeps using the displayed seed until unchecked; otherwise each recording chooses a random seed and fills the editable input. Switching history fills the input with that recording's seed. A manually entered pending seed survives reopening. Snapshots and options persist in the existing editor state; recording and history switching have undo checkpoints. New recording scope remains the current clip without selection, or selected notes/ranges with selection. Choosing a historical recording restores that saved clip prediction state.

Note annotations keep pronunciation at the upper left and `重录 n` at the upper right, reserving space between them; original lyrics remain inside the note. Request UUID, explicit seed and take number are passed per note and filtered by rest segment. A continuous phrase uses the newest active recording's seed. Independent rest-separated segments retain their existing requests. The prediction cache includes the effective seed/request, and downstream cache dependencies still follow their tensor inputs. Restoring a saved request reuses valid caches and can reproduce it after eviction.

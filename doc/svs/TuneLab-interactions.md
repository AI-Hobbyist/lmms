# TuneLab 操作对照记录

2026-10-05，实机 TuneLab 2.1.1，用户指定路径；Computer Use `@oai/sky`。只作行为参考，不作为任何依赖。用户进一步明确：只对齐钢琴窗部分操作，无关操作不加入。SVS 钢琴窗操作以 TuneLab 为准，在计划书范围内尽量对齐；LMMS 外壳/主题不改变此要求。

| 项目 | 实机观察 | SVS 实现要求 |
| --- | --- | --- |
| 空白单击 | 音符工具在空白单击未创建音符 | 单击/拖动用于选择，双击创建 |
| 空白双击 | 创建音符，处于可继续调尾操作；时间落在网格位置 | 创建使用当前量化和声库默认歌词；不能采用普通 LMMS 单击画音符 |
| 右边缘拖动 | 保留音符起点，修改尾部，按量化落点 | 独立右边缘命中与 resize transaction |
| 主体拖动 | 保留时长，时间与音高同时变化 | 独立移动操作，多选整体移动；所属手动音素跟随 |
| 左边缘拖动 | 尾部保持原位置，音符起点向左扩展 | 独立左边缘命中，保持尾部，按网格约束起点 |
| 音符右键 | 提供当前位置切分、复制/剪切、Shift+上下移八度、批量歌词入口 | 对齐计划内菜单语义，不增加参考里的计划外命令 |
| 双击歌词 | 音符矩形内出现输入框，文本选中 | Qt 行内输入，不使用模态对话框 |
| 输入确认 | 编辑框内输入 la 后原音符仍显示原值，Enter 后显示 la | 预编辑不写模型，确认一次提交；IME 组合输入不提交 |

实机使用临时未命名工程，未保存参考工程或复制其资源。截图不纳入发行材料。Ctrl 多选、IME 组合/Esc、Pitch/参数、缩放滚动及编辑事务需在 M3 继续实机核对；源码映射见 M0 契约。计划外参考功能不加入 SVS。

- 框选：在空白处拖框，选中框内第二个音符。
- Ctrl+C 后点击另一处空白并 Ctrl+V：粘贴音符出现在工程播放游标 0，保留原音高；不会按最后鼠标空白点粘贴。SVS 钢琴窗键盘粘贴按传输游标转换到当前片段局部时间，右键粘贴按右键定位。编曲区仍遵守计划书指定插入游标。
- 歌词导航：第二音符双击进入行内输入后 Shift+Tab 跳到前一个音符的歌词输入框，并使目标音符可见。
- 音高自由笔：启用波形状音高工具，从长音符内拖至后续短音符之后；用户音高线穿越小节、音符尾部和音符间空隙，保持连续，不按音符分段。
- 参数自由笔：在音量参数区横向拖动形成连续笔触，时间坐标与音符区一致；已画区域外保留原参数值。
- 用户补充：钢琴窗工具切换也必须对齐；M3 检查切换后的鼠标行为、命中优先级、光标和未完成操作的提交/取消，仅实现计划内工具。
- 音高锚点工具：从自由笔切到锚点后工具按钮显示激活状态，原曲线可见节点；曲线上单击未创建新节点，双击创建节点并显示切线手柄。M3 对齐该创建和工具状态语义。
